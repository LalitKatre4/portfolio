# Arjun Sharma - Portfolio Website

A modern, high-performance portfolio website built for an MCA graduate and Full Stack Developer using **React**, **TypeScript**, and **Tailwind CSS**.

## Features
- ⚡ **Ultra Fast**: Optimized bundle with lazy loading and code splitting.
- 🎨 **Glassmorphism & Particle Canvas**: Sleek dark aesthetic with interactive particle background.
- 📱 **Fully Responsive**: Mobile-first layout with smooth slide-out navigation.
- 🛠️ **Tech Stack Filter**: Interactive category filtering with animated progress bars.
- 🚀 **Featured Projects**: Interactive card layouts with GitHub/live demo action buttons.

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run local development server:
```bash
npm start
```

3. Build production bundle:
```bash
npm run build
```
